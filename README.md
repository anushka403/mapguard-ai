# mapguard-ai
MapGuard AI is a Python-based map error detection prototype that identifies potential location inaccuracies by comparing reported coordinates with OpenStreetMap reference data. Built with Streamlit, it provides an interactive dashboard for analyzing map issues and visualizing location discrepancies.

🎯 Project Objective

The objective of MapGuard AI is to demonstrate how geographic data validation techniques can help identify potentially inaccurate map locations and support map quality improvement.
